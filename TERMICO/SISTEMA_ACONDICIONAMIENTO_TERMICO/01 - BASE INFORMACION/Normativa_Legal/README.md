# Normativa Legal
**Qué hay:** Marco regulatorio del acondicionamiento térmico en Chile: OGUC, NCh 853, NCh 1079, resoluciones MINVU.
**Qué guardar:** Documentos .md o .pdf con leyes, normas y reglamentos vigentes.
**Cómo leer:** El Agente Revisor consulta aquí para validar cumplimiento normativo de los cálculos.
> Incluir fecha de vigencia en el nombre del archivo.
