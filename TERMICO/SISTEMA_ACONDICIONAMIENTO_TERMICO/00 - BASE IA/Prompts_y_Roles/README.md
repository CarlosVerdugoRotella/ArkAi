# Prompts y Roles
**Qué hay:** Instrucciones de comportamiento para cada Agente de IA (Extractor, Calculista, Revisor, Redactor).
**Qué guardar:** Archivos .md con system prompts por agente; plantillas de instrucciones reutilizables.
**Cómo leer:** Cada agente debe leer su archivo de rol antes de ejecutar cualquier tarea.
> Solo lectura para la IA. No modificar sin revisión del Arquitecto.
