# Checkpoints del Sistema
**Qué hay:** Estados de guardado del avance del sistema — puntos de restauración validados.
**Qué guardar:** Archivos .md o .json con estado del sistema; registro de versiones estables.
**Cómo leer:** El checkpoint más reciente = estado actual aprobado. Leer al iniciar cada sesión.
> Nombrar: CHK_YYYYMMDD_descripcion.md
