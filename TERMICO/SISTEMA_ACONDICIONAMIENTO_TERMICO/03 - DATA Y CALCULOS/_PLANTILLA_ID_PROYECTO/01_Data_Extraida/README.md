# 01 — Data Extraída
**Qué hay:** JSON bruto generado por el Agente Extractor (datos_extraidos.json).
**Qué guardar:** JSON del proyecto, versiones corregidas, logs de alerta.
**Cómo leer:** Verificar "listo_para_calculo": true antes de continuar. Si es false, el flujo está detenido.
> Este JSON es el puente entre los datos del proyecto y el motor de cálculo.
